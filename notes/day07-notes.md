## 知识点总结

### 1. 数组定义
- 创建数组：类型[] 数组名 = new 类型[数组长度];
- 静态初始化数组：类型[ ] 数组名 = {数组元素1,数组元素2...};
- 动态初始化数组：类型[ ] 数组名 = new 类型[长度]  只确定数组的数据类型和长度

| 数据类型                     | 动态初始化数组元素默认值 |
| ---------------------------- | ------------------------ |
| byte、short、int、long、char | 0                        |
| float、double                | 0.0                      |
| boolean                      | false                    |
| 类、接口、数组、String       | null                     |


### 2. 数组遍历
遍历就是一个个数据的访问  求和 元素搜索 找最大值 找最小值  

### 3. 二维数组
1. 静态初始化二维数组：类型[][] 数组名 = { {元素1,元素2...}, {元素1,元素2...}...};

2.  动态初始化二维数组：类型[][] 数组名 = new 类型[行数][列数];

3. 把二维数组的某一行存为一个一维数组：类型[ ] 一维数组名 = 二维数组名[第n行];
 
4. 访问长度：数组名.lengt

## 面试小题（Day9）
**Q：Java 中数组是对象吗？**
> A：是的。数组是对象，存放在堆中，有 length 属性，也有对应的 Class 对象。

**Q：数组和 ArrayList 的区别？**
> A：数组长度固定、效率高、可存基本类型；ArrayList 长度可变、功能丰富、只能存对象。
