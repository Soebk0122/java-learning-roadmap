##  知识点
### 1. 运算符  
1. 算术运算符：+（加）（与字符串可以用作连字符）、-（减）、*（乘）、/（除）、\、%（取余）

2. 关系运算符：==（等于）、!=（不等于）、>（大于）、<（小于）、>=（大于等于）、<=（小于等于）   
成立返回true 不成立返回false
3. 逻辑运算符：&&（逻辑与）、||（逻辑或）、!（逻辑非）

4. 位运算符：&（每个条件满足时返回true，否则返回false）、||（满足一个条件返回true，否则返回false）、!（取反，你真我假，你假我真）、^（前后条件结果相同时返回false，不同返回 true）、~、<<、>>、>>>

&&左边是false 跳过右边 || 左边是true 跳过右边

5. 赋值运算符：=、+=、-=、*=、/=、%= 具有强制类型转换功能 先运算后赋值 a+=b a=a+b

6. 三元表达式：表达式？值1：值2（真：返回值1 假: 返回值2）

### 2. 自增自减
1. 自增自减运算符：++、--
2. 在变量前后单独使用是没有区别的
3. 在变量前面使用 先加减后用 在变量后面使用 先用后加减

### 3. 方法
方法完整格式：修饰符 返回值类型 方法名(参数列表){方法体（需要执行的功能代码）}  

方法的返回值：无返回值void类型和有返回值的数据类型   
方法可以重载的：方法名相同，参数列表不同

### 4. 键盘录入
先导包：import java.util.Scanner;  
创建对象：Scanner sc = new Scanner(System.in);  
获取数据：sc.next对应的数据类型比如Int、Double();  String不需要
最后输出

### 5.类型转换
1. 强制类型转换：(数据类型)变量名  （大范围转换为小范围）
2. 自动类型转换：范围小的数据类型可以自动转换为范围大的数据类型，如：int转long、float转double

### 6.表达式的自动类型提升
1. 表达式的最终结果类型是由表达式中的最高类型决定的。

2. 在表达式中，如果存在byte、short、char类型，则表达式中的所有数据类型都会自动提升为int类型。

## 面试小题
**Q：i++ 和 ++i 的区别？**
> A：
> - `i++` 是先使用原值，再自增
> - `++i` 是先自增，再使用新值
> ```java
> int i = 1;
> System.out.println(i++); // 输出1
> System.out.println(++i); // 输出3
> ```  

 **Q：int和 Integer 的区别？**
> A：
> - `int` 是基本数据类型，`Integer` 是引用数据类型
> - int 是基本类型，Integer 是它的包装类；int 不能为 null，Integer 可以；集合和泛型只能用 Integer；比较值用 equals，不用 ==   
> 

 **Q：== 和 equals 的区别？**
 > A：
 > - `==` 是判断两个对象是否相等，`equals` 是判断两个内容是否相等
 > - 基本类型用 ==，引用类型比内容用 equals；   
  == 比地址，equals 比值；   
 > String、Integer 记得重写过 equals。
